# JME Ads - প্রিমিয়াম আর্নিং প্ল্যাটফর্ম (Web App & User Panel)

একটি পূর্ণাঙ্গ, আধুনিক ও দ্রুতগতির অনলাইন আর্নিং প্ল্যাটফর্ম। এতে রয়েছে বিজ্ঞাপন দেখে ইনকাম, ১৫ সেকেন্ড স্মার্ট কাউন্টডাউন টাইমার, লাকি স্পিন হুইল, রেফারেল কমিশন সিস্টেম, বিকাশ ও নগদ উইথড্রয়াল গেটওয়ে এবং সম্পূর্ণ কন্ট্রোল সমৃদ্ধ অ্যাডমিন প্যানেল।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **টাস্ক ও স্মার্টলিংক সেন্টার (Ad Tasks):**
   - ১৫ সেকেন্ড সিকিউর টাইমার ও চিট প্রিভেনশন (ট্যাব পরিবর্তন বা দ্রুত ফিরে এলে কাজ বাতিল)।
   - প্রতিটি লিংকে দৈনিক নির্ধারিত লিমিট।
   - প্রতি টাস্কে স্বয়ংক্রিয় ব্যালেন্স যোগ ও ট্রানজাকশন হিস্টোরি।

2. **লাকি স্পিন হুইল (Lucky Spin Wheel):**
   - দৈনিক নির্ধারিত স্পিন ও তাৎক্ষণিক ক্যাশ পুরষ্কার।
   - স্মুথ অ্যানিমেশন ও উইনিং সাউন্ড এফেক্ট।

3. **রেফারেল আর্নিং সিস্টেম (Referral System):**
   - ইউনিক রেফারেল কোড ও ওয়ান-ক্লিক কপি লিংক।
   - রেফার করা বন্ধুদের তালিকা ও রেফারেল বোনাস ট্র্যাকিং।

4. **বিকাশ ও নগদ উত্তোলন (Withdrawal Gateway):**
   - bKash ও Nagad ইনস্ট্যান্ট উইথড্র রিকোয়েস্ট।
   - সর্বনিম্ন উত্তোলন সীমা ও স্ট্যাটাস ট্র্যাকিং (Pending, Processing, Approved, Paid, Rejected)।

5. **লাইভ পেআউট নোটিফিকেশন (Live Payout Ticker):**
   - বাস্তবসম্মত বাংলাদেশি ইউজারদের নিয়মিত বিকাশ/নগদ উত্তোলনের লাইভ ফ্লোটিং নোটিফিকেশন।
   - কোনো বাটনের সাথে ওভারল্যাপ না হওয়ার নিখুঁত পজিশনিং।

6. **সিকিউর অথেনটিকেশন (Authentication):**
   - ইমেইল অথবা মোবাইল নম্বর ও পাসওয়ার্ড দিয়ে তাৎক্ষণিক নিরাপদ লগইন।
   - ইনলাইন বাংলা এরর মেসেজ ও টোস্ট নোটিফিকেশন।
   - পাসওয়ার্ড দেখার জন্য আইকন টগল (Show/Hide Password)।

7. **অ্যাডমিন প্যানেল (`admin.html`):**
   - ব্যালেন্স এডিট, ইউজার অ্যাক্টিভেশন/সাসপেন্ড।
   - নতুন টাস্ক/বিজ্ঞাপন যুক্ত ও এডিট।
   - উইথড্রয়াল রিকোয়েস্ট অ্যাপ্রুভ/রিজেক্ট।
   - গ্লোবাল ব্রডকাস্ট নোটিফিকেশন ও সেটিংস কন্ট্রোল।

## 📁 ফাইল ও ফোল্ডার পরিচিতি (Project Structure)

```text
├── src/                  # React + TypeScript + Tailwind সোর্স কোড
│   ├── components/       # রিইউজেবল কম্পোনেন্টস (Header, BottomNav, AuthModal, etc.)
│   ├── context/          # গ্লোবাল স্টেট ও লজিক (AppContext)
│   ├── pages/            # অ্যাপ পেজসমূহ (HomePage, TasksPage, SpinPage, etc.)
│   └── data/             # ডিফল্ট টাস্ক ও সেটিংস
├── public/               # পাবলিক স্ট্যাটিক ফাইলস
│   ├── admin.html        # অ্যাডমিন প্যানেল
│   ├── data.json         # বিজ্ঞাপন ও সেটিংস ডাটা
│   ├── manifest.json     # PWA কনফিগারেশন
│   └── user-panel.zip    # হোস্টিংয়ের জন্য ওয়ান-ক্লিক জিপ ফাইল
├── user-panel/           # রেডি-টু-হোস্ট স্ট্যাটিক ফাইলস (dist)
│   ├── index.html        # মূল এন্ট্রি ফাইল
│   ├── style.css         # স্টাইলশিট
│   ├── script.js         # অ্যাপ্লিকেশন লজিক
│   ├── data.json         # বিজ্ঞাপন সেটিংস
│   └── admin.html        # অ্যাডমিন প্যানেল
├── package.json          # প্রজেক্ট ডিপেন্ডেন্সিস
└── vite.config.ts        # Vite বিল্ড কনফিগারেশন
```

## 🚀 লোকাল ডেভেলপমেন্ট (Local Setup)

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন (Port 3000)
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```

## 🌐 যেকোনো ফ্রি হোস্টিং বা cPanel-এ আপলোড করার নিয়ম

1. **`user-panel/`** ফোল্ডারের ভেতরের সমস্ত ফাইল অথবা **`public/user-panel.zip`** আনজিপ করে আপনার হোস্টিংয়ের `public_html` ডিরেক্টরিতে আপলোড করুন।
2. কোনো নোড.জেএস (Node.js) সার্ভারের প্রয়োজন নেই; সম্পূর্ণ প্রজেক্টটি সাধারণ যে কোনো স্ট্যাটিক হোস্টিং (GitHub Pages, Netlify, Vercel, InfinityFree, Hostinger, cPanel)-এ চোখের পলকে লোড হবে।
